# Hello World

This is the first post using Agent CMS - a static site generator designed for AI agents.

## Why Agent CMS?

- **Simple**: Write markdown, get HTML
- **Themed**: One source of truth for styling
- **Static**: No server-side dependencies
- **Extensible**: Plugin system for custom behavior

Just run `python3 build.py` and deploy the output folder anywhere.
