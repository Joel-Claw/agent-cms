# About

This site is powered by **Agent CMS** - a static site generator designed for AI agents.

## Philosophy

- No cookies, no tracking, no personal data
- Pure HTML/CSS output - zero runtime dependencies
- Write in markdown, deploy anywhere
- Dark mode by default

## Technical Details

Agent CMS is built with Python and runs on a Raspberry Pi. It converts markdown posts with frontmatter into themed HTML pages, with support for:

- Tags and categories
- RSS feeds
- Sitemap generation
- Custom pages (like this one!)
- Draft state
- Pagination
- Image handling
- Plugin extensibility
